# Айдаһар жұмыртқасы — Blender blockout сахнасы

30 секундтық, 16:9 (1280×720, 24 fps) эскиз-видео. Seedance / Genjutsu арқылы
шынайы кадрға айналдыруға арналған қозғалыс пен камера референсі.

**Сюжет:** адам орманда мүкті тастардың үстімен келе жатады → бір «тасқа» басқанда
аяғы оны жарып ішіне кіріп кетеді → ол жерге көмілген алып айдаһар жұмыртқасы
болып шығады, жерден көтеріліп шығады → жұмыртқа жарқырап жарылады, ішінен бала
айдаһар шығып қанатын жаяды → адам тізерлеп қолын созады, басынан сипайды →
айдаһар алғаш көрген адамына еркелеп, басын кеудесіне басады, адам оны құшақтайды.

## Сахнадағы элементтер

- **Орман:** 150 үлкен мүкті ағаш, бұтақтар мен жапырақ шоғыры, ~700 қырыққұлақ, ~140 бұта,
  құлаған бөренелер, шағын саңырауқұлақтар, ағын су және оның үстіндегі тас жол.
- **Жұмыртқа:** 1.6 м, қара-көкшіл қабық, төбесі мүкпен жабылған (басында жай тас сияқты).
  Қабық ~45 бөлікке «сындырылған»: аяқ тиген жердегі бөліктер ішке түседі, жарықтар
  арасынан алтын жарық шығады, жарылғанда бөліктер физикамен (ауырлық, соқтығысу) шашырайды.
- **Адам:** манекен-риг (IK аяқ/қол), тот түсті күрте, қараңғы шалбар, қоңыр етік.
- **Бала айдаһар:** көгілдір қабыршақ, ақшыл іш, сүйек түсті мүйіз бен арқа тікенектері,
  үлкен алтын көз (жыпылықтайды, соңында жұмылады), ашылатын жақ, жиналатын/жайылатын қанат,
  құйрығы бұлғаңдайды, аяқтары өздігінен қадам басады.
- **Жарық:** жылы күн сәулесі ағаштар арасынан, жұмыртқа ішіндегі алтын жарық (пульс, жарылыс жарқылы).

## Қайта құру және рендер

Blender 5.2 (немесе `pip install bpy==5.2.3`, Python 3.13):

```bash
# сахнаны нөлден құру (~5 с)
python build_scene.py --out dragon_egg_scene.blend
# немесе Blender арқылы:
blender -b -P build_scene.py -- --out dragon_egg_scene.blend

# барлық 720 кадрды рендерлеу (Cycles CPU, 8 сэмпл + денойз, ~8 с/кадр)
python render.py --blend dragon_egg_scene.blend --out renders/frames --range 1-720
# жылдам тексеру (бірнеше кадр, жарты өлшем)
python render.py --blend dragon_egg_scene.blend --out /tmp/check --frames 180,372,690 --percent 50

# кадрлардан видео
ffmpeg -framerate 24 -i renders/frames/frame_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4
```

Blender-де ашқанда: камералар `CAMERAS` коллекциясында, таймлайндағы `SH01…SH07`
маркерлері камераларды өздігінен ауыстырады. Уақытты, қозғалысты өзгерту үшін
`build_scene.py` ішіндегі `Track(...)` кілттерін (кадр, мән) түзетіп, скриптті қайта іске қосыңыз.
