# 🎭 Telegram Mafia Bot

4–50 ойыншыға арналған Telegram Мафия ойынының боты: топтық чатта ойын бөлмесі, рөлдерді
кездейсоқ тарату, жеке чаттағы түнгі әрекеттер мен дауыс беру, ₸ валютасы, дүкен,
Telegram Stars арқылы алмаз сатып алу, рөл таңдау, профиль, рейтинг және күнделікті сыйлық.

**Технологиялар:** Python 3.11+, [aiogram 3](https://docs.aiogram.dev), PostgreSQL (asyncpg).

---

## Мүмкіндіктер

- **Ойын бөлмесі** — топта `/game`: тіркелу хабары бекітіледі, «🎮 Ойынға қосылу» батырмасы
  ойыншыны ботпен жеке чатқа апарады (бот тек өзімен чат бастаған адамға жаза алады).
  Кемінде 4, ең көбі 50 ойыншы; 50 адам жиналса ойын бірден басталады.
- **Рөлдер** — ойыншылар санына қарай автоматты баланс (`mafia_bot/game/balance.py`), 50 ойыншыда
  спецификациядағы құрам дәл сақталады. Әр ойыншы рөлін тек жеке чаттан біледі.
- **Түн / күн** — түнгі әрекеттер мен дауыс беру жеке чатта батырмалар арқылы; таңертең топта
  кім қаза тапқаны және оның рөлі жарияланады. Барлығы таңдау жасаса, кезең ерте аяқталады.
- **Модерация** — бот топта әкімші болуы керек: түнде топқа жазылған хабарламалар өшіріледі,
  өлген ойыншылардың жазуы ойын соңына дейін шектеледі (супертопта) және хабарламасы өшіріледі.
- **Команда чаты** — Дон/мафия/Киллер, екі Қорғаушы және Комиссар/Сержанттар ботқа жазған
  хабарламасы арқылы бір-бірімен жасырын сөйлесе алады. Өлген ойыншы бір «соңғы сөз» жаза алады.
- **Экономика** — жеңіс үшін ₸, дүкен (🛡 Қорғаныс 100 ₸, 📄 Жалған құжат 160 ₸),
  💎 алмаз (Telegram Stars), ⚖️ дауыс беруден қорғаныс, 💥 тесіп өтетін оқ, 🎭 рөл таңдау (1 💎).
- **Профиль, 🏆 рейтинг, 🎁 күнделікті сыйлық** (10 → 50 ₸, 7 күндік цикл).
- **Сенімділік** — валюта операциялары транзакциямен; әр ойынның бірегей ID-і бар, сыйақы бір рет
  беріледі; әр төлемнің `telegram_payment_charge_id`-і бірегей, алмаз екі рет қосылмайды.
  Бот қайта іске қосылса, аяқталмаған ойындар тоқтатылып, шектеулер алынады.

## Жоба құрылымы

```
mafia_bot/
├── game/              # Telegram-ға тәуелсіз ойын логикасы
│   ├── roles.py       # рөлдер, фракциялар, сипаттамалар
│   ├── balance.py     # 4–50 ойыншыға рөл құрамы, кезең уақыттары
│   └── engine.py      # күй машинасы: түнгі есептеу, дауыс беру, жеңіс шарттары
├── economy.py         # сыйақы, дүкен бағалары, алмаз пакеттері, күнделікті сыйлық
├── controller.py      # лобби, таймерлер, кезеңдер, хабарламалар (Notifier/Storage интерфейстері)
├── db/                # PostgreSQL сұлбасы және репозиторий
└── bot/               # aiogram: хэндлерлер, пернетақталар, мәтіндер, төлемдер
tests/                 # 220+ тест: қозғалтқыш, симуляция, контроллер, база, aiogram e2e
```

Ойын кезеңдері — `engine.Phase` күй машинасы (`LOBBY → NIGHT → DAY → VOTE → … → ENDED`).
Контроллер Telegram API-ді тікелей шақырмайды, сондықтан бүкіл ойынды жалған мессенджермен тестілеуге болады.

## Іске қосу

### 1. Боттың баптаулары (@BotFather)

1. `/newbot` — бот құрып, токенді алыңыз.
2. Алмаз сату үшін Telegram Stars қолданылады — бөлек төлем провайдері қажет емес.
3. Бот топта барлық хабарламаны көруі үшін оны **әкімші** етіңіз (әкімші боттар privacy
   режимінде де барлық хабарламаны алады). Қажетті құқықтар: *хабарламаларды өшіру*,
   *қатысушыларды шектеу*, қаласаңыз *хабарламаларды бекіту*. Бот мәзіріндегі
   «➕ Ботты топқа қосу» сілтемесі осы құқықтарды автоматты түрде сұрайды.

### 2. Docker Compose арқылы

```bash
cd telegram-mafia-bot
cp .env.example .env        # BOT_TOKEN және ADMIN_IDS толтырыңыз
docker compose up -d --build
```

### 3. Жергілікті іске қосу

```bash
cd telegram-mafia-bot
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env        # BOT_TOKEN, DATABASE_URL
python -m mafia_bot
```

Сұлба бот іске қосылғанда автоматты түрде құрылады (`mafia_bot/db/schema.sql`).

### Жиі кездесетін қателер

| Журналдағы хабар | Не істеу керек |
|---|---|
| `BOT_TOKEN көрсетілмеген` / `BOT_TOKEN қате` | `.env` ішіндегі `BOT_TOKEN`-ге @BotFather берген токенді бос орынсыз толық көшіріңіз |
| `Telegram серверіне қосылу мүмкін болмады` | Компьютердің интернетін тексеріңіз (Telegram бұғатталған желіде VPN/прокси керек) |
| `PostgreSQL-ге қосылу мүмкін болмады` | `DATABASE_URL` тексеріңіз; Docker-сіз іске қоссаңыз, хост `db` емес, `localhost` болуы керек |
| Топта «әкімші құқықтары керек» | Ботты топ әкімшісі етіп, «хабарламаларды өшіру» және «қатысушыларды шектеу» құқықтарын беріңіз |
| Бот ойыншыға рөл жібере алмады | Ол ойыншы ботпен жеке чатты ашып, **START** басуы керек |

### Орта айнымалылары

| Айнымалы | Әдепкі | Сипаттама |
|---|---|---|
| `BOT_TOKEN` | — | @BotFather берген токен |
| `DATABASE_URL` | — | `postgresql://user:pass@host:5432/db` |
| `ADMIN_IDS` | бос | Бот әкімшілерінің Telegram ID-лері (`/refund`, `/give`, кез келген топта `/stop`) |
| `REGISTRATION_SECONDS` | `120` | Тіркелу ұзақтығы |
| `TIME_SCALE` | `1.0` | Түн/күн/дауыс уақытының көбейткіші |
| `RESTRICT_DEAD` | `true` | Өлген ойыншылардың жазуын шектеу (супертопта) |
| `SILENCE_NIGHT` | `true` | Түнде ойыншылардың топтағы хабарламаларын өшіру |
| `MUTE_NON_PLAYERS` | `false` | Ойын кезінде ойынға қатыспайтындардың хабарламаларын өшіру |
| `REQUIRE_ADMIN_RIGHTS` | `true` | Әкімші құқығынсыз ойын ашуға тыйым салу |
| `LOG_LEVEL` | `INFO` | Журнал деңгейі |

## Командалар

**Топта:** `/game` — тіркелуді ашу, `/startgame` — бірден бастау (ашқан адам не әкімші),
`/extend` — +30 сек, `/leave` — шығу, `/stop` — тоқтату (әкімші), `/rules`.

**Жеке чатта:** басты мәзір (🎮 Ойынға қосылу, 🏠 Ойын бөлмесін ашу, 👤 Менің профилім, 🛍 Дүкен,
💎 Алмаз сатып алу, 🎭 Рөл таңдау, 📜 Ережелер, 🏆 Рейтинг, 🎁 Күнделікті сыйлық, ❓ Көмек),
сондай-ақ `/profile`, `/shop`, `/daily`, `/rating`, `/rules`, `/paysupport`, `/terms`.

**Бот әкімшісіне:** `/refund <telegram_payment_charge_id>` — Stars төлемін қайтару (алмаз шегеріледі),
`/give <user_id> <tenge|diamonds> <сан>` — баланс түзету.

## Бекітілген ережелер

Спецификацияда «нақты бекітілуі керек» деп қалдырылған жерлер былай шешілді:

**Түнгі есептеу реті:** әрекеттерді жинау → 💻 Хакер → 🛡 Қорғаушылар → 👨‍⚕️ Дәрігер → 🤵 мафия →
🔪 Киллер → 🪓 Қанішер → 🕵️ Комиссар → 🍾 Қайыршы → 🔥 бомбалар → 🧙‍♀️ Сиқыршы → 💣 Камикадзе →
🐺 Қасқырлар → өлімдерді бекіту → жеңіс тексеру → таңғы хабар. Барлық әрекеттер бір мезгілде
есептеледі: сол түні өлген ойыншының әрекеті де орындалады (тек Хакер тоқтата алады).

- **Дон / мафия** — Донның таңдауы шешуші; Дон бұғатталса не таңдамаса, мафия мүшелерінің
  көпшілік дауысы (тең болса — кездейсоқ). Дон «өткізу» басса — шабуыл жоқ. Дон өлсе, бірінші
  мафия мүшесі жаңа Дон болады. Мафия өз командасына шабуыл жасай алмайды.
- **Киллер** — мафия фракциясында, мафияны таниды, әр түнде бөлек өлтіреді.
- **Қорғаушылар** — мафия жағында, бірақ мафияны танымайды (мафия да оларды танымайды).
  Бас қорғаушы таңдаған Дон/мафия сол түні Комиссарға «Тұрғын» болып көрінеді және келесі күні
  дарға асылмайды. Бас қорғаушы өлсе, екіншісі келесі түннен бастап бас болады.
  Мафияның паритетінде Қорғаушылар есептелмейді, бірақ мафиямен бірге жеңеді.
- **Комиссар** — тексеру шынайы рөлді көрсетеді; бірінші түні ату жоқ. Сержанттар тексеру
  нәтижесін алады, Комиссар өлсе — бірінші Сержант Комиссар болады.
- **Дәрігер** — емделген адам сол түнгі барлық шабуылдан және бомбадан аман қалады; өзін бір рет,
  бір адамды қатарынан екі түн емдей алмайды. Камикадзе мен Сиқыршының жазасынан құтқармайды.
- **Хакер** (бейбіт) — нысананың түнгі әрекетін жояды; бір адамды қатарынан екі түн бұғаттамайды.
- **Қайыршы** (бейбіт) — барған үйіне сол түні кімдер келгенін (атын) біледі.
- **Камикадзе** — оны түнде өлтірген әр шабуылдаушы бірге өледі (Дәрігер де, қорғаныс та
  тоқтатпайды). Пиро бомбасынан өлсе — қарсы әсер жоқ.
- **Сиқыршы** (бейбіт) — оған алғаш шабуыл жасалғанда аман қалады және шабуылдаушыны
  ⚔️ жазалайды не 🕊 кешіреді (30 сек; жауап болмаса — кешіреді). Сиқыр бір рет жұмыс істейді.
  Пиро бомбасынан қорғамайды.
- **Пиро (Бомбалаушы)** — әр түнде бір бомба қояды; кемінде 3 тірі адамда бомба болғанда
  жарып жібере алады (өзі де өледі). Жарылыс кезіндегі барлық бомбаланған тірі ойыншы сол түні
  өлсе — Пиро жеңеді. Дәрігер бомбадан құтқарады (Пиро сонда жеңіледі), 🛡 қорғаныс құтқармайды.
- **Қасқыр** — бейбіт болып бастайды; мафия не Киллер шабуылдаса — өлмей мафияға қосылады,
  Комиссар атса — өлмей Сержант болады; Қанішер мен бомбадан өледі.
- **Қанішер** (тәуелсіз) — әр түнде өлтіреді; тірі ойыншылардың соңғы екеуінің бірі болса жеңеді.
  Қанішер тірі болса, мафия паритетпен жеңе алмайды.
- **Өзін-өзі өлтіруші** (тәуелсіз) — дарға асылса жеңеді; ойын жалғаса береді.

**Жеңіс:** бейбіттер — Дон/мафия/Киллер/Қанішер түгел жойылса; мафия — Дон+мафия+Киллер саны
қалғандардан (Қорғаушыларсыз) кем болмаса және Қанішер жоқ болса. Қатарынан 3 цикл өлімсіз өтсе
немесе 40 күннен асса — тең ойын. Жеңімпаз фракцияның тірі және өлген мүшелері сыйақы алады,
ойыннан қашқандар алмайды.

**Заттар:**
- 🛡 *Қорғаныс* — бір ойында бір рет, бірінші өлімге әкелетін шабуылдан (мафия, Киллер, Қанішер,
  Комиссардың оғы). Дәрігер сол түні емдеген болса, жұмсалмайды. Ешкімге жарияланбайды.
- 📄 *Жалған құжат* — ойын басында рөліңіз Дон/мафия/Пиро/Қанішер болса ғана іске қосылады
  (сол ойынға жұмсалады), Комиссардың бірінші тексеруінде «Тұрғын» көрсетеді.
- ⚖️ *Дауыс беруден қорғаныс* — дарға асылуға таңдалғанда бір рет құтқарады
  (Өзін-өзі өлтірушіде қолданылмайды). Түнгі шабуылдан қорғамайды.
- 💥 *Тесіп өтетін оқ* — Дон (мафияның ортақ шабуылы), Киллер, Комиссар (ату) не Қанішер
  болғанда нысананың 🛡 қорғанысын бұзады. Тек қорғаныс шын бұзылғанда жұмсалады; Дәрігерді,
  Сиқыршыны, Камикадзені, Қасқырды айналып өтпейді. Қосымша шабуыл құқығын бермейді.
- 🎭 *Рөл таңдау* — кезекке қойылады (ең көбі 5). Ойын басында кезектің бірінші рөлі, ол сол
  ойыншылар санында бар болса және басқа біреу ертерек сатып алмаса, беріледі. Берілмесе, таңдау
  сақталады және бот «💎 Алмазды қайтару» батырмасын жібереді. Ойын кезінде қайтаруға болмайды.
- Ойын бот қайта іске қосылуы не `/stop` арқылы тоқтаса, ешбір зат жұмсалмайды, сыйақы берілмейді.

**Жеңіс сыйақысы:** кестедегі нүктелер (4 → 20 ₸, 10 → 30, 20 → 40, 30 → 50, 40 → 60, 50 → 70)
дәл сақталады, аралық сандар сызықтық есептеліп, бүтінге дөңгелектеледі.

**Күнделікті сыйлық:** 10, 15, 20, 25, 30, 35, 50 ₸; 24 сағатта бір рет (уақыт PostgreSQL
серверінен алынады), 48 сағаттан көп үзіліс болса цикл басынан басталады.
