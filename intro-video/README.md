# Айназ — таныстыру интросы (моушн-дизайн, 16:9)

Толық видео ~2 минут болады. Мұнда **алғашқы 10.5 секунд** дайын: алтын фон,
қошқар мүйіз ою-өрнегі, қазақша шрифттар, карта (Қазақстан → Алматы облысы →
Кеген ауданы → Кеген ауылы), фотолар, диктор дауысы, музыка және дыбыстық эффектілер.
Бәрі кодпен жасалған, кадр-кадрмен рендерленеді.

## Дикторлық мәтін

> Мен — Оралбекқызы Айназ. 2004-ші жылы қыркүйектің 2-сі Алматы облысы Кеген
> ауданы Кеген ауылында өмірге келдім.

Дауыс: Piper TTS, ISSAI KazakhTTS (F1 Raya) — офлайн. Әр фраза бөлек
синтезделеді, сондықтан анимация дауысқа дәл байланған (`scene/js/cues.js`).

## Таймлайн (0–10.5 с)

| Уақыт | Дауыс | Көрініс |
|---|---|---|
| 0.0–0.8 | — | Қараңғыдан алтын жарық ашылады, рамка мен розетка-ою сызылады |
| 0.4–2.2 | «Мен — Оралбекқызы Айназ.» | Қыз шығады, «ОРАЛБЕКҚЫЗЫ» әріп-әріппен, «Айназ» жарқылмен |
| 2.5–5.3 | «Екі мың төртінші жылы, қыркүйектің екісі,» | «2004» сандары айналып тоқтайды, «қыркүйектің 2-сі» |
| 5.2–6.6 | «Алматы облысы,» | Қазақстан картасы сызылады, Алматы облысы көгілдір боп ерекшеленеді |
| 6.8–7.7 | «Кеген ауданы,» | Зум → Кеген ауданы, шекарасы сызылады, арка фотосы шығады |
| 7.9–10.0 | «Кеген ауылында өмірге келдім.» | Зум → Кеген ауылы, белгі түседі, ауыл фотосы, жазу |

## Құрылым

```
scene/            HTML/Canvas/SVG сахна (index.html, js/, fonts/, data/, assets/places/)
tools/
  cutout.py         суреттен фонды алып тастау (rembg + BiRefNet-portrait, офлайн)
  voice.py          қазақша диктор дауысы (Piper) + scene/js/cues.js
  audio.py          музыка + SFX синтезі, дауыспен микс
  build_base_geo.py Қазақстан силуэті, көлдер, өзендер (Natural Earth)
  build_region_geo.py  Алматы облысы, Кеген ауданы (geoBoundaries, офлайн)
  fetch_osm_geo.py  нақты OSM шекаралары (Overpass API қолжетімді болса)
  render.mjs        Playwright → кадрлар → ffmpeg (mp4)
```

## Рендер

```bash
pip install rembg onnxruntime piper-tts shapely numpy pillow
python3 tools/cutout.py path/to/photo.jpg         # scene/assets/portrait-cutout.png
python3 tools/voice.py --model kk-issai-high.onnx  # .cache/build/voice.wav + cues.js
python3 tools/audio.py                             # .cache/build/intro-mix.wav
node tools/render.mjs --workers 4                  # out/intro-0-10s.mp4 (~2 мин)
node tools/render.mjs --still 2.0,7.5              # тексеруге арналған кадрлар
```

Браузерде алдын ала қарау: `intro-video` ішінде `python3 -m http.server`,
сосын `http://localhost:8000/scene/index.html` (басу — дыбыспен қайта ойнату).

Портрет суреті жеке болғандықтан репозиторийге салынбайды (`.gitignore`).

## Карта деректері

- Қазақстан силуэті, көлдер, өзендер — Natural Earth 10m.
- Алматы облысы (2022 жылғы шекара) — geoBoundaries ADM2 аудандарының бірігуі
  (Жетісу облысы аудан шекаралары бойынша бөлінген, сондықтан шекара дәл).
- **Кеген ауданы**: офлайн деректерде 2018 жылға дейінгі Райымбек ауданы ғана бар
  (қазіргі Кеген + Райымбек). Сондықтан сыртқы шекара нақты, ал шығыстағы ішкі шекара
  ойдан сызылмай, бөлектеу шығысқа қарай солғындайды. Ауыл контуры да жоқ, ауыл
  нақты координатасы бойынша белгімен және шеңбермен көрсетілген.
- `overpass-api.de` қолжетімді болғанда `python3 tools/fetch_osm_geo.py` нақты
  OSM шекараларын (Кеген ауданы rel 9159398, ауыл контуры way 38804393, көшелер)
  `scene/data/osm-geo.json`-ға жазады, сахна оны автоматты түрде қолданады.
