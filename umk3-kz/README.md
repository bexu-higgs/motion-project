# UMK3 (SNES) — қазақша аударма құралдары

Бұл қалтада Ultimate Mortal Kombat 3 (SNES) ойынын қазақшаға аударатын скрипттер мен аударма мәтіні бар.
**Ойынның өзі (ROM/APK) мұнда сақталмайды**: құралдар сіздің APK файлыңыздан қазақша нұсқаны жинайды.
Дайын нұсқа тек жеке пайдалануға арналған. Ойынның құқығы Warner Bros./Midway компаниясына тиесілі, сондықтан оны таратпаңыз.

## Қалай жұмыс істейді

* `tools/cyr.py`, `tools/shade.py` — жаңа кириллица әріптері (Ә Б Г Ғ Д Ж З И Й Қ Л Ң Ө П У Ұ Ф Ц Ч Ш Щ Ы Ь Э Ю Я Һ; Ч, Щ, Ь, Һ тек кіші шрифтте).
  Ойынның өз әріптерінен үйренген жарық-көлеңке моделімен боялады, сондықтан стилі сәйкес.
  А, В, Е, К, М, Н, О, Р, С, Т, Х, І, Ү әріптері ойынның латын әріптерімен бірдей.
* `tools/mklz.py` — ойынның мәтін сығу форматы (кері LZ) үшін декодер мен оңтайлы компрессор.
* `tools/build.py` — кіші шрифт пен әріп кестелерін ROM-ның бос аймағына ($FF:DC80) көшіреді,
  үлкен шрифтке 23 әріп қосады, мәтіндерді сығып орнына салады, мәзір жолдарын ауыстырады.
* `tools/voice.py`, `tools/apply_voice.py` — WAV/MP3 жазбаларды SNES BRR форматына (6000 Гц) айналдырып,
  түпнұсқа клиптің орнына қояды. Ұзындығы мен құрылымы өзгермейді.
* `tools/mkapk.py` — түпнұсқа APK ішіндегі `rom.zip`-ті ауыстырады, `targetSdkVersion`-ды 24-ке көтереді
  (әйтпесе Android 14+ орнатпайды), сосын `jarsigner` арқылы қол қойылады.
* `text/kz_text.py` — бүкіл аударма. Түзету үшін осы файлды өзгертіп, қайта жинаңыз.

## Жинау

```sh
pip install numpy scipy pillow     # emu.py-мен тексеру үшін: pip install stable-retro
tools/make_all.sh <түпнұсқа.apk> out [дауыс_қалтасы]
# нәтиже: out/umk3_kz.apk және out/umk3_kz.sfc
```

Дауыс қалтасындағы файл аты клип нөмірінен басталуы керек (`52.wav`, `44_round2.mp3`).
Клиптер тізімі мен ең ұзақ уақыты `voice_catalog.json` файлында.
