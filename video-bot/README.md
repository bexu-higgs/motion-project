# 🎬 Видео жүктеуші бот — қазақ тілінде

YouTube, TikTok, Instagram, Facebook және Threads видеоларын жүктеп беретін Telegram боты.
Ботқа видеоның сілтемесін жібересіз, ол файлды чатқа жібереді.

## Мүмкіндіктер

- **YouTube** — бот видеоны бірден жүктемейді. Алдымен YouTube-та қолжетімді **барлық сапаларды**
  (2160p, 1440p, 1080p60, 720p, 480p, 360p…) өлшемімен бірге батырма етіп шығарады.
  Сол тізімде **тек аудио** алуға арналған батырмалар да бар:
  - 🎧 **MP3** (192 кбит/с) — кез келген ойнатқышта ашылады, мұқабасы мен атауы қосылады;
  - 🎧 **M4A** — YouTube-тағы түпнұсқа дыбыс, қайта кодталмайды.

  Бір видеодан бірнеше нұсқа алуға болады, мысалы алдымен 720p, сосын MP3.
- **TikTok, Instagram, Facebook, Threads** — видео бірден **ең жақсы сапада** келеді. TikTok-тың
  **су белгісі бар** нұсқасы ешқашан таңдалмайды. Су белгісіз нұсқа мүлде болмаса ғана (өте сирек)
  бар нұсқасы жіберіледі.
- **Instagram/Threads карусельдері** — жазбадағы барлық видео бір альбом болып келеді (10-ға дейін).
- Видео мен дыбыс жеке ағын болса, бот оларды **біріктіреді** (ffmpeg). Нәтиже — Telegram-да бірден
  ойнайтын MP4 файл, H.264 кодегіне басымдық беріледі.
- **Прогресс**: «⬇️ Жүктелуде… 45%» хабарламасы жүктеу барысын көрсетіп тұрады.
- **Қайта жүктемейді**: бір видео бұрын жіберілген болса, Telegram-дағы көшірмесі бірден қайта жіберіледі
  (бот қайта іске қосылғанша есте сақталады).
- Топтарда да жұмыс істейді: бот хабарламадағы сілтемені көрсе, видеоны сол хабарламаға жауап етіп жібереді.
  Топтағы басқа хабарламаларға жауап бермейді.

## ⚠️ Telegram-ның 50 МБ шегі

Telegram-ның қарапайым (бұлттағы) Bot API арқылы бот **50 МБ-тан** үлкен файл жібере алмайды.
Сондықтан:

- YouTube тізімінде одан үлкен сапалар 🚫 белгісімен көрсетіледі (басқанда бот себебін түсіндіреді);
- басқа платформаларда видео 50 МБ-қа сыймаса, бот одан төменірек **ең жақсы** сапаны өзі таңдайды.

Үлкен файлдар (2000 МБ-қа дейін) керек болса, [жеке Bot API серверін](#жеке-bot-api-сервері-2000-мб-қа-дейін)
іске қосыңыз.

## Орнату — бәрі терминалда

### 1. @BotFather-да бот жасау

Telegram-да @BotFather ботына `/newbot` деп жазып, жаңа бот жасаңыз — ол **токен** береді.

### 2. Бір командамен орнату

**Linux / macOS** — терминалға мына жолды қойыңыз:

```bash
curl -fsSL https://raw.githubusercontent.com/bexu-higgs/motion-project/main/video-bot/install.sh | bash
```

Скрипт кодты `~/video-bot` қалтасына жүктейді, Python кітапханаларын (yt-dlp, deno т.б.) орнатады
және баптау шеберін ашады. Python 3.10+ керек. ffmpeg-ті де орнатқан жөн:

```bash
sudo apt install python3 python3-venv ffmpeg     # Ubuntu / Debian
brew install python ffmpeg                       # macOS
```

**Windows** — PowerShell-ге кезекпен:

```powershell
cd $HOME
curl.exe -L -o video-bot.zip https://codeload.github.com/bexu-higgs/motion-project/zip/refs/heads/main
tar -xf video-bot.zip
cd motion-project-main\video-bot
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m videobot.setup
```

Python-ды https://www.python.org/downloads/ сайтынан орнатыңыз («Add python.exe to PATH» белгісін қойыңыз).
Windows-та ffmpeg бөлек орнатылмаса да болады — ол pip пакетімен бірге келеді.

### 3. Баптау шебері

Шебер терминалда кезекпен сұрайды:

1. **Токен** — BotFather берген токенді қойыңыз, шебер оны тексереді.
2. **Cookies файлы** (міндетті емес) — қазір жоқ болса, Enter басыңыз. Төменде қараңыз.
3. **Құралдар** — ffmpeg пен JavaScript ортасының (deno) бар-жоғын тексеріп, жоқ болса не істеу керегін айтады.

Соңында ботты бірден іске қосуды ұсынады. Шеберді қайта іске қосуға болады:
`.venv/bin/python -m videobot.setup` (бұрынғы жауаптар Enter арқылы сақталады).

### Кейін іске қосу

```bash
~/video-bot/start.sh            # Linux / macOS
```

Windows-та `video-bot` қалтасындағы `start.bat` файлын ашыңыз. Бот жұмыс істеп тұруы үшін терминал
ашық тұруы керек; тоқтату — `Ctrl+C`.

### Жаңарту — маңызды!

YouTube, TikTok және Instagram сайттарын жиі өзгертеді. Сонда yt-dlp-тың жаңа нұсқасы шығады.
Бот бір күні видео жүктей алмай қалса, алдымен **орнату командасын қайта іске қосыңыз**: код пен yt-dlp
жаңарады, ал `.env` пен `cookies.txt` сақталады. Тек yt-dlp-ты жаңарту үшін:

```bash
~/video-bot/.venv/bin/python -m pip install -U "yt-dlp[default]"
```

### Серверде тоқтаусыз жұмыс істету (systemd)

```ini
# /etc/systemd/system/video-bot.service
[Unit]
Description=Telegram video downloader bot
After=network-online.target

[Service]
User=ПАЙДАЛАНУШЫ_АТЫ
WorkingDirectory=/home/ПАЙДАЛАНУШЫ_АТЫ/video-bot
ExecStart=/home/ПАЙДАЛАНУШЫ_АТЫ/video-bot/start.sh
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now video-bot
journalctl -u video-bot -f        # логтарды көру
```

## Cookies: YouTube «бот» деп бөгесе немесе Instagram кіруді сұраса

Бот серверде (VPS) тұрса, YouTube кейде «Sign in to confirm you're not a bot» деп бөгейді.
Instagram мен Facebook кейбір видеоларды тек аккаунтқа кірген адамға көрсетеді. Мұндайда бот
пайдаланушыға себебін жазады, ал сіз браузердің cookies файлын қоса аласыз:

1. Браузерге **Get cookies.txt LOCALLY** кеңейтімін орнатыңыз (Chrome / Firefox).
2. Негізгі емес, **бөлек аккаунтпен** youtube.com (не instagram.com) сайтына кіріңіз. Аккаунт бұғатталуы
   мүмкін, сондықтан жеке аккаунтыңызды қолданбаңыз.
3. Кеңейтім арқылы `cookies.txt` файлын экспорттап, бот қалтасына (`~/video-bot/cookies.txt`) салыңыз.
   Бірнеше сайттың cookies-ін бір файлға біріктіруге болады.
4. Шеберді қайта іске қосып, файл жолын көрсетіңіз (немесе `.env` ішіне `COOKIES_FILE=cookies.txt` деп жазыңыз).

Cookies файлы — аккаунтқа кіру кілті. Оны ешкімге бермеңіз (ол `.gitignore`-да тұр).

## Жеке Bot API сервері (2000 МБ-қа дейін)

1. https://my.telegram.org сайтынан `api_id` пен `api_hash` алыңыз.
2. [telegram-bot-api](https://github.com/tdlib/telegram-bot-api) серверін құрастырып, **бот тұрған
   компьютерде** `--local` режимінде іске қосыңыз:
   `telegram-bot-api --api-id=ID --api-hash=HASH --local`
   Docker-де іске қоссаңыз, бот қалтасын контейнерге **сол жолмен** қосыңыз (бот серверге файл жолын береді).
3. Ботты бұлттағы серверден бір рет шығарыңыз: браузерде `https://api.telegram.org/bot<ТОКЕН>/logOut` ашыңыз.
4. `.env` ішіне `BOT_API_URL=http://localhost:8081` деп жазып, ботты қайта іске қосыңыз.
   Шек өздігінен 2000 МБ болады (`MAX_FILE_MB` арқылы өзгертуге болады).

## Командалар

| Команда | Сипаттамасы |
|---|---|
| `/start` | Сәлемдесу және қысқаша нұсқаулық |
| `/help` | Толық көмек: қолдау көрсетілетін сілтемелер, өлшем шегі |

Командасыз да жұмыс істейді: жай сілтеме жіберсеңіз жеткілікті.

## Баптаулар (`.env`)

| Айнымалы | Әдепкі | Сипаттамасы |
|---|---|---|
| `BOT_TOKEN` | — | @BotFather токені (міндетті) |
| `COOKIES_FILE` | — | Netscape форматындағы cookies файлы |
| `MAX_FILE_MB` | `50` (`BOT_API_URL` болса — `2000`) | Жіберілетін файлдың ең үлкен өлшемі |
| `BOT_API_URL` | — | Жеке Bot API серверінің мекенжайы |
| `PROXY` | — | Сайттарға прокси арқылы қосылу (`socks5://…`, `http://…`) |
| `MAX_PARALLEL` | `3` | Бір уақытта қатар жүретін жүктеулер |
| `DOWNLOAD_DIR` | `downloads` | Уақытша файлдар (жіберілген соң бірден өшіріледі) |

## Жоба құрылымы

```
video-bot/
├── install.sh            # бір командамен орнату (Linux / macOS)
├── start.sh / start.bat  # ботты іске қосу
├── videobot/
│   ├── links.py          # хабарламадан сілтеме табу, платформаны анықтау
│   ├── formats.py        # сапалар тізімі, су белгісіз ең жақсы форматты таңдау
│   ├── downloader.py     # yt-dlp: талдау, жүктеу, біріктіру, 50 МБ шегін бақылау
│   ├── threads.py        # Threads экстракторы (yt-dlp-та жоқ)
│   ├── bot.py            # Telegram: мәзір, батырмалар, прогресс, файл жіберу
│   ├── texts.py          # барлық қазақша мәтіндер
│   ├── config.py         # баптаулар
│   └── setup.py          # терминалдағы баптау шебері
└── tests/                # желісіз тесттер (жалған сайт пен жалған Telegram)
```

## Әзірлеушілерге

```bash
pip install -r requirements-dev.txt
pytest
```

Тесттер желіге шықпайды: `tests/conftest.py` ffmpeg арқылы шағын видеолар жасап, оларды жергілікті HTTP
сервер мен жалған экстрактор арқылы береді. Сондықтан yt-dlp-тың нақты ағыны тексеріледі: сапа
таңдау, видео мен дыбысты біріктіру, MP3, су белгісі бар нұсқаны өткізіп жіберу, шекке сыймағанда
төменірек сапаға ауысу. Telegram бөлігі жалған бот арқылы тексеріледі.

**Ескерту:** авторлық құқықты құрметтеңіз. Ботты тек өзіңізге тиесілі немесе жүктеуге рұқсат етілген
видеолар үшін қолданыңыз.
