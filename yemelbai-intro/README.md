# YEMELBAI FILMS × VeoSeeBot — фильм интросы

Минимализм стиліндегі кинематографиялық интро: **1920×1080, 16:9, 24 fps, 15 сек**, H.264 + AAC 320 kbps стерео дыбыс.
Интро YEMELBAI FILMS логотипінен басталып, фильмнің толықтай **VeoSeeBot** ЖИ платформасында жасалғанын көрсетеді.

**Дайын видео:** [`output/YEMELBAI_FILMS_VeoSeeBot_Intro_1080p.mp4`](output/YEMELBAI_FILMS_VeoSeeBot_Intro_1080p.mp4)

## Логотип

Жіберілген суреттегі VeoSeeBot логотипі фонынан тазартылып, **векторға** айналдырылды (`tools/trace_logo.py`, potrace),
сондықтан экранда үлкен болса да анық. Бөлек қолдануға болатын файлдар:

- `assets/logo.svg` — векторлық логотип (түсі `currentColor`, фоны жоқ)
- `assets/veoseebot-logo-white.png`, `assets/veoseebot-logo-black.png` — мөлдір фондағы PNG (2640 px)

## Файлдар

- `timeline.js` — барлық уақыт белгілері мен мәтіндер (сурет те, дыбыс та осыны оқиды)
- `intro.html` — анимацияның өзі (Canvas). Браузерде ашсаңыз — алдын ала қарау: басу / Space — ойнату, төменгі жолақ — айналдыру
- `audio.py` — дыбыс дизайны, ешқандай дайын үлгісіз, numpy/scipy арқылы синтезделген
- `render.mjs` — кадрларды headless Chromium-да рендерлеп, ffmpeg-ке береді
- `build.sh` — бәрін бір командамен құрастырады
- `tools/` — логотипті векторлау (`trace_logo.py`) және PNG-ге экспорттау (`export_logo_png.js`)
- `fonts/` — Inter Display (SIL Open Font License)

## Өзгерту және қайта құрастыру

Мәтінді, логотип өлшемін (`logoScale`) немесе уақытты өзгерту үшін тек `timeline.js` файлын түзетіңіз, сосын:

```bash
pip install numpy scipy        # бір рет
./build.sh                     # ~2 минут
```

Қажет: Python 3, Node.js + Playwright (Chromium), ffmpeg. Логотипті қайта векторлау үшін — potrace:
`python3 tools/trace_logo.py логотип.jpg`.
Тексеру үшін жеке кадрлар: `node render.mjs --stills 2,7.6,10` → `output/stills/`.
