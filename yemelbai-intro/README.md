## Логотиптер

Жіберілген суреттердегі логотиптер фонынан тазартылып, **векторға** айналдырылды (potrace),
сондықтан экранда үлкен болса да анық. Ziyo Fest AI логотипі түс-түсімен бөлек қабаттарға бөлінді
(көгілдір, алтын, пиксель шаршылар, ақ шеңбер, жазу), түстері түпнұсқадан алынды: алтын `#e8a020`, көгілдір `#027c8c`.
Бөлек қолдануға болатын файлдар (`assets/`):

- `logo.svg`, `veoseebot-logo-white.png`, `veoseebot-logo-black.png` — VeoSeeBot (мөлдір фон, 2640 px)
- `ziyo-logo.svg`, `ziyo-fest-ai-logo.png` — Ziyo Fest AI түпнұсқа түстерімен (мөлдір фон)
- `ziyo-logo-on-dark.svg`, `ziyo-fest-ai-logo-on-dark.png` — қараңғы фонға арналған нұсқа (жазуы ақ)

## Файлдар

- `timeline.js` — барлық уақыт белгілері мен мәтіндер (сурет те, дыбыс та осыны оқиды)
- `intro.html` — анимацияның өзі (Canvas). Браузерде ашсаңыз — алдын ала қарау: басу / Space — ойнату, төменгі жолақ — айналдыру
- `audio.py` — дыбыс дизайны, ешқандай дайын үлгісіз, numpy/scipy арқылы синтезделген
- `render.mjs` — кадрларды headless Chromium-да рендерлеп, ffmpeg-ке береді
- `build.sh` — бәрін бір командамен құрастырады
- `tools/` — логотиптерді векторлау (`trace_logo.py`, `trace_ziyo.py`) және PNG-ге экспорттау (`export_logo_png.js`)
- `fonts/` — Inter Display (SIL Open Font License)

## Өзгерту және қайта құрастыру

Мәтінді, логотип өлшемін (`logoScale`) немесе уақытты өзгерту үшін тек `timeline.js` файлын түзетіңіз, сосын:

```bash
pip install numpy scipy        # бір рет
./build.sh                     # ~3–4 минут, үш видеоны бірден шығарады
```

Қажет: Python 3, Node.js + Playwright (Chromium), ffmpeg. Логотиптерді қайта векторлау үшін — potrace:
`python3 tools/trace_logo.py veoseebot.jpg`, `python3 tools/trace_ziyo.py ziyo.jpg`.
Тексеру үшін жеке кадрлар: `node render.mjs --stills 2,7.6,10` → `output/stills/`.
