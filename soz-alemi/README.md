# Сөз әлемі — балаларға арналған сөйлеу ойындары

Тұтықпаны түзетуге арналған 3 деңгейлі ойын-тапсырма сайты.

**Тақырыбы:** Сөздік қор мен байланыстырып сөйлеуді дамыту.

| Деңгей | Тапсырма | Не істейді |
|---|---|---|
| 🟢 1 — жеңіл | «Суретті ата» | Анимациялы суретке қарап, заттың атауын айтады. «Көмек» алғашқы дыбысты, кейін буындарды көрсетеді. |
| 🟡 2 — орташа | «Сөйлем құрастыр» | Берілген сөздерден сөйлем айтады, сосын сөздерді ретімен басып сөйлемді «жинайды». |
| 🔴 3 — күрделі | «Әңгімені жалғастыр» | Айдос пен күшік туралы әңгіменің басын оқиды, 3 сұраққа жауап береді (ой-көмекші суреттер бар), соңында 3–5 сөйлемнен әңгіме құрайды. |

## Ерекшеліктері

- **Тіркелусіз.** Сайтты ашып, «Бастау» батырмасын басса болды. Логин мен құпиясөз қажет емес.
- **Асықтырмайды.** Таймер жоқ, «қате» деген белгі жоқ, кез келген талпыныс мадақталады (тапсырмадағы ескертуге сай).
- **Тыныс алу жаттығуы:** сөйлер алдында «гүлді иіскеу / шамды үрлеу» әдісімен босаңсуға арналған.
- **Ата-аналар мен педагогтарға** арналған бөлім: тақырып, мақсат, барлық тапсырма мен жауаптар, бағалау критерийлері және ескерту.
- Жұлдыздар мен прогресс тек осы құрылғыда (`localStorage`) сақталады, ешқайда жіберілмейді.
- Құрылғыда қазақ тіліндегі дауыс болса, «Тыңда» батырмасы шығады (мысалы, Windows-тағы Microsoft Edge).
- 3-деңгейде әңгімені дыбысқа жазып, қайта тыңдауға болады. Бұл міндетті емес, жазба құрылғыдан шықпайды.
- Дизайн iOS «Liquid Glass» стилінде жасалған: мөлдір шыны панельдер, жұмсақ анимациялар, «Dynamic Island» хабарламалары.
- Телефонға, планшетке және компьютерге бейімделген. Телефонда «Басты экранға қосу» арқылы қолданба сияқты ашылады.

## Файлдар

```
soz-alemi/
├── index.html             — бет
├── css/style.css          — дизайн
├── js/content.js          — БАРЛЫҚ МӘТІН мен тапсырмалар (түзету үшін осы файл)
├── js/app.js              — ойын логикасы
├── fonts/                 — Nunito қарпі (қазақ әріптерін толық қолдайды)
├── emoji/svg, emoji/anim  — Noto эмодзи суреттері мен Lottie анимациялары
├── vendor/                — lottie-web ойнатқышы
└── icons/                 — белгішелер мен превью-сурет
```

Сайт статикалық. Сервер, база және сыртқы сервис қажет емес, кез келген хостингте жұмыс істейді.

## Жалпыға қолжетімді ету (GitHub Pages)

1. Бұл өзгерістер `main` тармағына біріктіріледі (merge).
2. Репозиторийде: **Settings → Pages → Build and deployment → Source: GitHub Actions** таңдалады (бір рет қана).
3. `.github/workflows/pages.yml` сайтты автоматты түрде жариялайды. Мекенжайы:
   **https://bexu-higgs.github.io/motion-project/**

Компьютерде тексеру үшін:

```bash
cd soz-alemi && python3 -m http.server 8000
# браузерде: http://localhost:8000
```
