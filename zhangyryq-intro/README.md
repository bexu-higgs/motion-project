# YEMELBAI FILMS — «ЖАҢҒЫРЫҚ» интросы

Минимализм стиліндегі кинематографиялық интро: **1920×1080, 16:9, 24 fps, 15 сек**, H.264 + AAC 320 kbps стерео дыбыс.

**Дайын видео:** [`output/YEMELBAI_FILMS_Zhangyryq_Intro_1080p.mp4`](output/YEMELBAI_FILMS_Zhangyryq_Intro_1080p.mp4)

## Идея

«Жаңғырық» — қайтып оралатын дыбыс. Интроның бүкіл қимылы осыдан шығады:
сызық (тыныш дыбыс толқыны) → студия логотипі → бір нүктеден тараған толқындар →
кері оралып, сөзге жиналатын жаңғырық → қайтадан сызық → нүкте → қараңғылық.
Басы мен соңы бір-біріне қарайды: фильм бір сызықтан басталып, бір нүктемен бітеді.

## Таймлайн

| Уақыт | Сурет | Дыбыс |
|---|---|---|
| 0.0 – 1.75 | Қараңғыдан жіңішке жарық сызық өседі | Терең суб-дрон, шу-райзер |
| 1.75 | Сызық саңылау секілді ашылып, **YEMELBAI** көрінеді (анаморфты жарқыл, хроматикалық сызат) | Терең соққы + шыны тон, реверб |
| 2.35 – 4.5 | **— FILMS —**, сосын **ҰСЫНАДЫ**; әріп аралығы баяу жиырылады | Ауа, жұмсақ шыны «дың» |
| 4.5 – 5.4 | Логотип бұлдырап, әріптері тарап, жоғалады | Төмен түсетін whoosh |
| 5.7 – 7.5 | Бір жарық нүкте — әр соғысында толқын-сақина тарайды | «Сонар» пингі, пинг-понг жаңғырығы |
| 7.3 – 8.2 | Атаудың елес көшірмелері сырттан ортаға жиналады | Кері реверб (reverse swell) |
| 8.2 | **ЖАҢҒЫРЫҚ** орнығады: жарқыл, соққы толқыны, жеңіл діріл | Үлкен соққы, E-минор аккорд |
| 8.2 – 11 | Атаудан 7 жаңғырық-елес біртіндеп тарайды | Сол сәттерде қайталанатын «шапалақ-жаңғырық» |
| 9.3 – 10.7 | Әріптердің үстінен жарық өтеді | Солдан оңға жылжитын жылтыр шу |
| 12.3 – 13.45 | Сөз сызыққа жаншылады, сызық нүктеге жиырылады | Сору дыбысы → соңғы соққы |
| 13.45 – 15.0 | Нүкте соңғы толқындарын шығарып, сөнеді | Соңғы пинг пен құйрық |

## Файлдар

- `timeline.js` — барлық уақыт белгілері мен мәтіндер (бір жерде; сурет те, дыбыс та осыны оқиды)
- `intro.html` — анимацияның өзі (Canvas). Браузерде ашсаңыз — алдын ала қарау: басу / Space — ойнату, төменгі жолақ — айналдыру
- `audio.py` — дыбыс дизайны, ешқандай дайын үлгісіз, numpy/scipy арқылы синтезделген
- `render.mjs` — кадрларды headless Chromium-да рендерлеп, ffmpeg-ке береді
- `build.sh` — бәрін бір командамен құрастырады
- `fonts/` — Inter Display (SIL Open Font License)

## Өзгерту және қайта құрастыру

Мәтінді (мысалы, атауды) немесе уақытты өзгерту үшін тек `timeline.js` файлын түзетіңіз, сосын:

```bash
pip install numpy scipy        # бір рет
./build.sh                     # ~2 минут
```

Қажет: Python 3, Node.js + Playwright (Chromium), ffmpeg.
Тексеру үшін жеке кадрлар: `node render.mjs --stills 2,8.4,10` → `output/stills/`.
