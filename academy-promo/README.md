# Higgsfield Academy — моушн-дизайн промо (Liquid Glass)

iOS-тағы «Liquid Glass» стиліндегі 60 секундтық промо-видео: мөлдір шыны әріптер, жарықты сындыратын
мұздатылған шыны панельдер, серіппелі (spring) iOS анимациясы, дыбыс дизайны және жеңіл эмбиент музыка.
Дикторлық мәтін (`audio/voiceover.mp3`, 57 с) видеоға қосылып, музыка дауыстың астында автоматты түрде
басылады (ducking).

## Дайын файлдар

| Файл | Формат |
|---|---|
| `output/higgsfield_academy_16x9_4k60.mp4` | 16:9, 3840×2160, 60 fps, дауыс + музыка + SFX (≈114 МБ — GitHub-тың 100 МБ шегінен үлкен, сондықтан git-те жоқ: `./build.sh` қайта жасайды) |
| `output/higgsfield_academy_16x9_1080p60.mp4` | 16:9, 1920×1080, 60 fps — 4K мастерден кішірейтілген көшірме |
| `output/higgsfield_academy_9x16_reels.mp4` | 9:16 (Reels), 1080×1920, 60 fps, дауыс + музыка + SFX |

| `output/audio/` | `music.wav`, `sfx.wav`, `bed.wav` — бөлек дыбыс жолдары |

(`cues()`) сол мәндерден есептеледі.

## Скриншоттар

Сабақ плиткаларындағы суреттер — ресми сайттың Academy бөлімінен (higgsfield.ai/academy, «AI Creation:
First Steps» курсы) 2026-11-03 күні түсірілген скриншоттар. Түпнұсқа толық беттер `assets/screens/raw/`
қалтасында, видеода қолданылған кесінділер `assets/screens/` қалтасында.
Ескерту: бұл ортада сайттың медиа CDN-і (`d2245ubjcvacnx.cloudfront.net`) желі саясатымен жабық болды,
сондықтан сабақ видеоларының мұқабалары беттерде жүктелмеді — кесінділер сабақ атауы, авторы және
материалдары көрінетін бөліктерден алынды (жүктелмеген суреттің «сынық» белгісі ғана жасырылды).

## Қалай жинау керек

Қажет: Node 18+, Playwright (Chromium), ffmpeg, Python 3 + numpy + scipy, Xvfb (Mesa llvmpipe үшін).

```bash
./build.sh audio/voiceover.mp3     # толық конвейер: дыбыс белгілері → дыбыс → 2 рендер → қоспа
```

Жеке қадамдар:

```bash
export DISPLAY=:99; Xvfb :99 &                       # llvmpipe (SwiftShader-ден ~3× жылдам)
node render.js --stills 3.5,10.5,27.5 --scale 0.5     # алдын ала қарау кадрлары (PNG)
node render.js --cues out/cues.json                   # дыбыс белгілерінің тізімі
python3 audio/synth.py out/cues.json out/audio         # музыка + SFX
node render.js --aspect 16x9 --scale 2 --out out/v.mp4 # 4K60
./mux.sh out/v.mp4 out/audio/bed.wav audio/voiceover.mp3 out/final.mp4
```

Браузерде тікелей қарау: `index.html?aspect=16x9&scale=0.5&play=1` (Space — пауза, ←/→ — айналдыру).

## Қалай жұмыс істейді

- `src/engine.js` — WebGL2 рендерер. Әр элемент — 3D кеңістіктегі спрайт; шыны пішіндер G-буферге
  нормаль/биіктік ретінде жазылады (дөңгелек төртбұрыш, доға, сызық, metaball үшін аналитикалық SDF,
  мәтін үшін тегістелген қашықтық картасы), содан кейін фонды сындырады: хроматикалық жиектер,
  спекуляр жарық, Френель жиегі, жұмсақ көлеңке, bloom.
- `src/scenes.js` — 8 сахна, камера және дыбыс белгілері; бәрі уақыттың таза функциясы (кадр дәлдігі).
- `render.js` — Chromium-ды басқарып, кадрларды YUV420 түрінде тікелей ffmpeg-ке жібереді.
- `audio/synth.py` — барлық дыбыс numpy/scipy арқылы нөлден синтезделеді (сэмплдер жоқ).
