# Отты Арал — оффлайн battle royale (Android)

Free Fire стиліндегі үшінші тұлғадан ойналатын «соңғы болып аман қал» ойыны. Толықтай қазақ тілінде,
интернетсіз жұмыс істейді: 39 бот + сен, ұшақтан секіру, парашют, тарылатын аймақ, олжа, «Мұз қабырға».

**Дайын APK:** [`release/OttyAral.apk`](release/OttyAral.apk) — Android 7.0+ (API 24), OpenGL ES 3.0.

## Ойын ерекшеліктері

- **Арал картасы** (1 км²): Бәйтерек ауылы, Әскери база, Ескі зауыт, Жайлау (киіз үйлер), Ескі қамал,
  Алмалы бау, Балықшылар айлағы, Жел диірмендері, Шамшырақ мүйісі. Ішіне кіруге болатын ғимараттар,
  баспалдақтар, жиһаз, кілемдер, сары газ құбырлары, айналатын жел диірмендері, мұржадан шыққан түтін.
- **Кейіпкерлер**: 6 киім үлгісі (Батыр, Сарбаз, Қалалық, Ару, Мерген, Томирис), қаңқалы анимация,
  қолдың IK-сы, бронежилет пен дулыға денеде көрінеді.
- **Қарулар**: «Барыс» тапаншасы, «Шапшаң» ПП, «Бүркіт» (АК), «Сұңқар» (M4), «Найзағай» бытыралы,
  «Қыран» мергендік мылтық (оптикасымен). Шегіну, шашырау, басқа тию, оқ іздері, гильзалар, оқ тесіктері.
- **Заттар**: бронежилет/дулыға 1–3 деңгей, дәрі қобдишасы, торсықтағы қымыз, Мұз қабырға, граната,
  әуе жүгі, өлім қорабы.
- **Боттар**: олжа жинайды, есік арқылы ғимаратқа кіреді, аймаққа көшеді, шайқаста бүйірлей жылжиды,
  мұз қабырға қояды, граната лақтырады, емделеді. Қиындығы: Жеңіл / Орташа / Қиын.
- **Графика**: процедуралық текстуралар (тас, кірпіш, ағаш, киіз, ою-өрнек, кілем…), splat-жер бедері,
  нақты уақыттағы көлеңкелер, су шейдері (Френель, көбік), бұлтты аспан, желмен тербелетін шөп пен ағаштар,
  ағаштарға LOD. Сапа: Төмен / Орташа / Жоғары / Ультра, автоматты ажыратымдылық.
- **FPS**: баптауларда 30 / 60 / 120 таңдауға болады; Android-та экранның 120 Гц режимі сұралады.
- **Дыбыс**: барлық SFX кодпен синтезделеді — әр қарудың атысы (жақын/алыс), оқтау, қадам (шөп, тас,
  ағаш, металл, құм, су), оқ тию, бас «дің», ысқырған оқ, жарылыс, мұз қабырға, ұшақ, жел, теңіз,
  құстар. Мәзірде домбыра, қобыз және дауылпазбен ойналатын қазақы әуен.

## Басқару

| Сенсорлы экран | Компьютер (тексеру үшін) |
|---|---|
| Сол жақ джойстик — жүру | WASD |
| Оң жақты сырғыту — қарау | Тышқан |
| Қызыл батырма — ату (сол жақта да бар) | Сол жақ батырма |
| Нысана батырмасы — дәл көздеу | Оң жақ батырма |
| Көк батырма — Мұз қабырға | G |
| Дәрі / Қымыз / Граната | H / J / Q |
| Оқтау, секіру, отыру | R, Space, C |

## Құрастыру

APK толық Android SDK-сыз жиналады (aapt2 + dx + apksig Maven Central-дан жүктеледі):

```bash
cd otty-aral
./tools/build_apk.sh          # нәтиже: release/OttyAral.apk
```

Қажет: JDK 17+, Node 18+, Python 3 + Pillow. Браузерде тексеру: `cd game && npm install && npm run dev`
(http://localhost:8080).

Қолтаңба кілті `tools/otty-release.p12` (құпиясөз `ottyaral`) — жаңартулар бір кілтпен орнатылуы үшін
репозиторийде сақталады. Google Play-ге жариялау үшін өз кілтіңізді `KEYSTORE=... KEYPASS=...` арқылы беріңіз.

## Құрылымы

```
otty-aral/
  android/        WebView қабығы (MainActivity: толық экран, 120 Гц, діріл)
  game/src/
    core/         баптаулар, қазақша мәтіндер, шу функциялары
    gfx/          процедуралық текстуралар, материалдар, геометрия біріктіру
    world/        жер бедері, физика, ғимараттар, өсімдіктер, аспан, су
    actors/       кейіпкер моделі, қарулар, ойыншы, бот миы
    game/         матч, атыс, олжа, аймақ, ұшақ, эффектілер, гранаталар
    audio/        DSP, SFX кітапханасы, музыка
    ui/           HUD, мәзірлер, енгізу
  tools/          APK құрастыру скрипттері
  release/        дайын APK
```
