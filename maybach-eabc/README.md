# Mercedes-Maybach GLS — E-ACTIVE BODY CONTROL референс-видеосы (Blender)

ЖИ видеоға арналған референс: көлік E-ABC режимінде орнында серпіліп тұр, салондағы
банка сусын шайқалса да ұстағыштан шықпайды, жүргізуші ырғаққа басын изеп «билейді»,
камера жүргізуші терезесінен артымен шығып, көлікті сырттан көрсетеді.

| Параметр | Мәні |
|---|---|
| Ұзақтығы | 15 с (450 кадр) |
| Формат | 9:16, вертикаль |
| FPS | 30 |
| Рендер | Cycles (CPU), 720×1280, 1080×1920-ға дейін үлкейтілген MP4 |
| Файлдар | `maybach_eabc_reference.mp4` — дайын видео, `maybach_eabc_reference.blend` — сахна |

## Таймлайн (бір үздіксіз кадр)

| Уақыт | Не болады | Камера |
|---|---|---|
| 0.0 – 0.8 с | Ұстағыштағы банка сусын, көлік тыныш | Банкаға жақын план, жоғарыдан |
| 0.8 – 1.8 с | E-ABC қосылады — серпіліс біртіндеп күшейеді | Банкада тұр; салон камераға қатысты тербеледі |
| 1.8 – 4.0 с | Көлік ырғақпен серпілуде; банка сәл шайқалады, бірақ орнынан қозғалмайды | Баяу кері тартылып, көтеріледі |
| 4.0 – 6.4 с | Жүргізуші басын ырғаққа изеп, жан-жаққа тербеп «билейді» | Рульдің үстімен жүргізушіге бұрылады |
| 6.4 – 9.6 с | Серпіліс жалғасуда | Жүргізуші есігінің ашық терезесінен **артымен** баяу сыртқа шығады |
| 9.6 – 15 с | Көлік толығымен көрінеді — шанағы дөңгелектердің үстінде секіріп, оңға-солға тербеледі | Алдыңғы / жүргізуші жақ бұрышына қарай доғамен жылжып, баяу алыстайды |

**Серпіліс параметрлері** (`build_scene.py` басында): жиілігі 1.6 Гц (~96 BPM),
тік амплитуда ±4.5 см (+3 см көтерілу), бүйірлік тербеліс ±2.5°, алдыңғы-артқы ±1.4°.
Дөңгелектер жерде қозғалмай тұрады — тек шанақ қозғалады.
Салонда камера шанақпен 50%-ға ғана бірге жүреді, сондықтан ішінде де серпіліс анық көрінеді;
сыртта камера жерге бекітілген.

## Сахнаны қайта жасау / рендерлеу

```bash
pip install bpy==5.2.3            # немесе Blender 5.x
python build_scene.py             # -> maybach_eabc_reference.blend

# кадрлар (GPU бар болса, Blender ішінде Cycles → GPU қойып, 1080×1920 / 32+ sample)
python render.py -- --blend maybach_eabc_reference.blend --out frames \
    --width 720 --height 1280 --samples 16

ffmpeg -framerate 30 -i frames/f_%04d.png \
    -vf "scale=1080:1920:flags=lanczos" -c:v libx264 -crf 16 -pix_fmt yuv420p \
    -movflags +faststart maybach_eabc_reference.mp4
```

Blender ішінде ашқанда: `BODY_EABC` — серпілетін шанақ (кілт кадрлар әр кадрда),
`CAN_PIVOT` — банка, `DRV_TORSO` / `DRV_HEAD` — жүргізуші, `Camera` — камера жолы.
Модель — стильдендірілген блокаут (логотипсіз), сыртқы түрін ЖИ сіздің фотоларыңыз
бойынша береді; бұл видео қозғалыс пен ракурс үшін.
