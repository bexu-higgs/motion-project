`soz-alemi/` қалтасында тұтықпаны түзетуге арналған 3 деңгейлі ойын-тапсырма сайты бар («Суретті ата», «Сөйлем құрастыр», «Әңгімені жалғастыр»). Тіркелу қажет емес: сайтты ашып, «Бастау» батырмасын басса болды.
