# motion-project
Бұл Instagram-ға арналған моушн-дизайн интро видеосының жобасы. Маған осы видеоның сценарийі мен таймлайн құрылымын жасауға көмектес

---

## 🐥 Сөз әлемі — балаларға арналған сөйлеу ойындары

`soz-alemi/` қалтасында тұтықпаны түзетуге арналған 3 деңгейлі ойын-тапсырма сайты бар («Суретті ата», «Сөйлем құрастыр», «Әңгімені жалғастыр»). Тіркелу қажет емес: сайтты ашып, «Бастау» батырмасын басса болды.

Толығырақ: [soz-alemi/README.md](soz-alemi/README.md) · Сайт: https://bexu-higgs.github.io/motion-project/

## 🎬 Монтажшы — кәсіби видеомонтаж ЖИ агенті

`montazhshy/` қалтасында дайын материалдан (видео, фото, музыка, диктор) сценарий бойынша кәсіби монтаж жасайтын ЖИ агенті бар: кадрларды көріп ретке қояды, кесулерді музыка битіне дәл түсіреді, дыбысты тазартып, музыканы сөз астында басады (−14 LUFS), түсті теңестіреді, ауысулар мен титрлер қосады, өз жұмысын тексереді және Premiere/DaVinci-ге экспорттайды. Браузердегі Студиясы мен терминал командалары бар; API кілтсіз «Автомонтаж» режимі де жұмыс істейді.

Толығырақ: [montazhshy/README.md](montazhshy/README.md)

curl -fsSL https://raw.githubusercontent.com/bexu-higgs/motion-project/main/montazhshy/install.sh | bash
