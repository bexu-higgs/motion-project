# motion-project
Бұл Instagram-ға арналған моушн-дизайн интро видеосының жобасы. Маған осы видеоның сценарийі мен таймлайн құрылымын жасауға көмектес

## 🎭 Telegram Mafia Bot

`telegram-mafia-bot/` қалтасында 4–50 ойыншыға арналған Telegram Мафия ботының толық коды бар
(aiogram 3 + PostgreSQL): рөлдер, түнгі әрекеттер, жеке чатта дауыс беру, ₸ валютасы, дүкен,
Telegram Stars арқылы алмаз, профиль, рейтинг және күнделікті сыйлық.
Сипаттамасы мен іске қосу нұсқаулығы: [telegram-mafia-bot/README.md](telegram-mafia-bot/README.md).
