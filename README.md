# motion-project — Higgsfield MAX жеңілдігі: моушн-дизайн туториал

16:9 · 1080p · 30 fps · ~4 мин 23 с · видеодағы барлық жазу мен дикторлық мәтін қазақша · тек Higgsfield сайтының өзі (скриншоттар, батырма атаулары) ағылшынша.

Дайын видео: `out/higgsfield-max-tutorial.mp4` (дикторсыз, тек жұмсақ UI дыбыстары — дауысты өзіңіз жазасыз, төменде қараңыз).

## Не ішінде

| Папка | Мазмұны |
|---|---|
| `assets/source/` | Сіз жүктеген түпнұсқа скриншоттар |
| `assets/cutouts/` | Скриншоттардан кесіп алынған 34 элемент (PNG) — CapCut т.б. үшін де жарайды |
| `src/regions.json` | Әр кесіндінің координаттары (бір жерден өзгертіледі) |
| `src/timeline.ts` | Сценарий: қазақша мәтін сөйлем-сөйлеммен + әр сөйлемнің уақыты |
| `src/copy.ts` | Экрандағы барлық қазақша жазу (тақырыптар, белгілер, түсіндірмелер) — бір жерден түзетіледі |
| `src/scenes/` | 10 сахна (S01…S10), брифтегі SCENE 1–10-ға сәйкес |
| `docs/voiceover-cue-sheet.md` | Дикторға арналған кесте: әр сөйлемнің басталу/аяқталу уақыты |
| `docs/voiceover-guide.srt` | Сол уақыттар SRT түрінде (тек жазу кезінде басшылыққа, видеоға қосылмайды) |
| `public/sfx/` | Скриптпен синтезделген жұмсақ UI дыбыстары (музыка жоқ) |

## Дауысты қосу (ұсынылатын жол)

1. `docs/voiceover-cue-sheet.md` кестесіндегі әр сөйлемді бөлек жазыңыз.
2. Файлдарды ID бойынша сақтаңыз: `public/vo/s1_1.wav`, `public/vo/s1_2.wav`, … (mp3/m4a да болады).
3. `npm run sync-vo` — нақты ұзақтықтар `src/vo-timings.json`-ға жазылады, барлық анимация дауысқа өздігінен қайта синхрондалады.
4. `npm run render` — дауысы бар жаңа видео шығады.

Бүкіл мәтін бір файлда болса (мысалы, AI-дауыс сервисінен алынған бір MP3): сөйлемдер ретімен, арасында қысқа үзіліспен оқылуы керек. Сонда `npm run split-vo -- narration.mp3` файлды 59 сөйлемге өзі бөліп, `public/vo/` ішіне сақтайды → кейін `npm run sync-vo` және `npm run render`.

Немесе дайын видеоны алып, дауысты монтаж бағдарламасында кесте уақыттарына қойсаңыз да болады.

## Командалар

```bash
npm install
npm run assets      # скриншоттардан кесінділер + бұлдыр фондар + SFX қайта жасау
npm run studio      # Remotion Studio — браузерде алдын ала көру/өңдеу
npm run render      # out/higgsfield-max-tutorial.mp4
npm run cues        # дикторлық кесте мен SRT-ны жаңарту
npm run split-vo -- narration.mp3   # бір ұзын дауыс файлын сөйлемдерге бөлу
npm run sync-vo     # public/vo/ ішіндегі дауыс ұзақтығына видеоны қайта уақыттау
npm run timeline    # сахна/сөйлем кадрларын шығару
```

Chromium жүктелмейтін ортада: `REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render`.

## Ескертпелер

- Мәзір жабық тұрған Explore беті скриншотта жоқ, сондықтан ол нақты элементтерден жиналды: браузер жолағы, нақты мәзір белгішесі, Upgrade батырмасы және беттің бұлдыр (фокустан тыс) көрінісі.
- Мәзірде тек **Log in** батырмасы бар; ол «Welcome to Higgsfield — Sign up and generate for free» терезесін ашады. Сондықтан Sign Up / Log In осы батырма арқылы көрсетілді.
- Профильдегі батырма интерфейсте **Go Premium** деп жазылған (мәтінде «Get Premium»), экрандағы жазулар интерфейске сәйкес.
- `05-max-1800-alt.jpg` скриншотында баға $45, ал сценарийде $59 — видеода сценарийдегі бағалар ($59 / $115 / $159) мен соларға сәйкес скриншоттар қолданылды.
- Remotion лицензиясы: жеке тұлғалар мен ≤3 адамдық командаларға тегін.
