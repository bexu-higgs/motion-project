Бұл Instagram-ға арналған моушн-дизайн интро видеосының жобасы. Маған осы видеоның сценарийі мен таймлайн құрылымын жасауға көмектес

## 🥤 «Шөлдеген адам» — Blender референс видео

`blender-reference-video/` қалтасында 24 секундтық, 16:9 форматтағы кинематографиялық референс видео бар. Шөлдеген адам тоңазытқыштан жалғыз банка табады, «бұл аз» деп ренжиді, сосын банканы «пыс» еткізіп ашады да, кішірейіп, оның үстіне секіреді. Соңында ұзын түтікшемен ішеді. Видео түссіз, біркелкі тегіс фонда түсірілген. Бүкіл сахна `scene.py` скриптімен құрылады.

Толығырақ: [blender-reference-video/README.md](blender-reference-video/README.md) · Видео: [shol-reference.mp4](blender-reference-video/shol-reference.mp4)
