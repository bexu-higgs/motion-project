# motion-project

Higgsfield AI course — **Module 03: Prompt Writing** («ПРОМПТ ЖАЗУДЫ ҮЙРЕНУ»).
A 120-second, 1920×1080 educational motion-design video in Kazakh that teaches beginners the *logic* of a prompt for AI image and video generation, rather than ready-made prompts to memorise.

Бұл жоба — промпт жазудың логикасын түсіндіретін моушн-дизайн сабағының сценарийі, таймлайны және толық анимациясы.

## How it is made

The whole video is code: every frame is a pure function of time drawn on a 1920×1080 canvas, so it can be previewed live, scrubbed, edited and re-rendered deterministically.

```
src/
  index.html            preview player (also the render target with ?render)
  js/core.js            easing, keyframes, colour, typography, prompt-text layout, icons
  js/ui.js              background, prompt fields, Generate button, generation reveal, callouts
  js/illus-city.js      the recurring shot: rainy neon street + walking character, 4 lighting setups
  js/illus-portrait.js  close-up / portrait and the Negative-Prompt artifact layers
  js/illus-desert.js    "one idea, two prompts" robot-in-a-desert pair
  js/timeline.js        scene registry, narration placement, cross-fades, audio cue export
  js/scenes/s1…s8       one file per scene
  data/vo-manifest.js   narration durations + word marks (generated)
script/voiceover.kk.json  narration (exact text, pronunciation hints, phrase splits)
audio/vo/                 narration clips (Piper TTS, ISSAI Kazakh voice)
audio/mix.m4a             final mix for the preview player (mix.wav is regenerated by tools/mix.py)
tools/
  vo.py                 synthesize narration          (needs tools/fetch_piper.sh)
  sfx.py                procedural sound effects (no samples, no music)
  render.mjs            headless Chromium → ffmpeg, parallel workers
  mix.py                bus processing, ducking, loudness, mux
  build.sh              everything end to end
```

## Preview

Open `src/index.html` in Chrome (works from `file://`). Space plays/pauses with the mixed audio, ←/→ step one second (Shift for a single frame), and the numbered buttons jump to each scene.

## Build

Requirements: Node 18+ with Playwright (Chromium), Python 3 with NumPy, ffmpeg.

```bash
tools/build.sh            # render frames + mix audio → renders/module03-prompt-writing.mp4
tools/build.sh --voice    # also re-synthesize the narration (downloads Piper + voice once)

node tools/render.mjs --stills 5,30,110     # quick PNG stills into build/stills/
node tools/render.mjs --from 40 --to 55     # render one section
```

Re-synthesizing narration produces new takes (the TTS duration model is stochastic); scene timings key off `data/vo-manifest.js`, so visuals follow automatically.
