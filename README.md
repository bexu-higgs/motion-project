# motion-project — «Референстермен жұмыс»

AI видео курсына арналған оқу моушн-дизайн видеосы: AI арқылы видео жасауда референстерді қалай қолдану керек.

- **Дайын видео:** [`output/referencetermen-zhumys.mp4`](output/referencetermen-zhumys.mp4)
- Формат: 9:16, 1080 × 1920, 30 fps, H.264 + AAC 48 kHz
- Ұзақтығы: 88 с (диктор аудиосы 85 с болғандықтан)
- Дыбыс: қазақша диктор + интерфейс SFX + баяу фондық музыка (диктор сөйлегенде музыка автоматты түрде басылады) + жұмсақ технологиялық фон

## Таймлайн

Сахналар диктордың сөйлемдеріне қиыстырылған (кідірістер `ffmpeg silencedetect` арқылы өлшенген, диктор видеоның 0.6 секундынан басталады).

## Құрылымы

```
src/
  index.html, styles.css   — 1080×1920 сахна, дизайн жүйесі (графит фон, көгілдір акцент, glassmorphism)
  timeline.js              — сахна уақыттары, VO офсеті, SFX белгілері (cue)
  main.js                  — фон, бөлшектер, прогресс, сахналар арасындағы өту, renderFrame(t)
  scenes/s1…s8             — 8 сахна
  shots.js                 — «генерацияланған» кадрлар (портрет, жүру, секіру, орталар)
  art/character.js         — кейіпкер портреті (векторлық иллюстрация)
  art/rig.js               — толық бойлы кейіпкер қаңқасы (жүру, секіру)
  art/env.js               — қала, орман, ғимарат, зертхана, стиль, студия, дала
scripts/
  render.mjs               — Chromium арқылы кадрларды параллель рендерлеу → ffmpeg
  audio.py                 — музыка + SFX синтезі және диктормен араластыру
  snap.mjs                 — жеке кадрлардың скриншоты (тексеру үшін)
assets/
  audio/voiceover.mp3      — диктор (ElevenLabs, Serik)
  fonts/                   — Inter (қазақ кириллицасын толық қолдайды, OFL)
```

Анимация толығымен `t` уақытының функциясы — кез келген кадрды кез келген ретпен рендерлеуге болады.

## Қайта құрастыру

Қажет: Node 18+, Python 3 (numpy, scipy), ffmpeg, Chromium (`CHROMIUM_PATH` арқылы жолын көрсетуге болады).

```bash
npm install            # playwright
npm run build          # кадрлар → build/video.mp4, аудио → build/mix.wav, нәтиже → output/
npm run preview        # бірнеше кадрдың скриншоты → build/preview/
```

## Ескерту

Мысал кейіпкер мен орталар — кодпен салынған векторлық иллюстрациялар (бұл ортада сурет генераторы жоқ). Бір дизайннан құрылғандықтан, кейіпкердің бет-әлпеті, шаш үлгісі, күртешесі және бетіндегі меңі барлық кадрда бірдей. Нақты AI-суреттерді қойғыңыз келсе, `src/assets.js` ішіндегі `hero_*` және орта суреттерін PNG файлдарымен ауыстыруға болады.
