# motion-project
Бұл Instagram-ға арналған моушн-дизайн интро видеосының жобасы. Маған осы видеоның сценарийі мен таймлайн құрылымын жасауға көмектес

## Нәтиже
`out/final.mp4`: 1080×1920 (9:16), 30 fps, 37.6 сек, дыбысы бар (AAC, ~−15 LUFS).

## Таймлайн
| Уақыт (сек) | Көрініс |
|---|---|
| 0–3.2 | Қараңғы фон, «MADE WITH», Claude логотипі (`> claude code` деген жол терілген түрде шығады), «×», Blender логотипі |
| 3.2–4.0 | Логотиптер жоғарыға жиналып, бір қатарлы «Claude × Blender» тақырыбына айналады |
| 3.8–11.0 | Blender блокауты дөңгелек бұрышты карточкада ойнайды, астында `01 BLOCKOUT` деген жазба мен таймкод тұрады |
| 9.9–10.7 | «+ Higgsfield Genjutsu» логотипі тақырыпқа қосылады |
| 11.0–12.3 | Лайм түсті сызық карточканы кесіп өтіп, блокауттан реалистік нұсқаға ауыстырады (кадрлар синхронды) |
| 12.7–13.7 | Карточка толық экранға дейін үлкейеді |
| 13.7–33.2 | Реалистік нәтиже толық экранда, кадр әрекетке қарай баяу жылжиды (pan) |
| 33.2–37.6 | Финал: «Claude × Blender + Higgsfield Genjutsu», соңында қараңғыға сөнеді |

Екі бастапқы клип те 30 сек және кадрма-кадр сәйкес келеді, сондықтан сюжет бір рет, үзіліссіз көрсетіледі: басы блокаут түрінде, қалғаны реалистік түрде. Дыбыс ретінде нәтиже видеосының өз дыбысы алынады, оған логотиптерге арналған жеңіл эффектілер (`src/audio.py`) қосылады.

## Қайта жинау
```
pip install opencv-python-headless numpy pillow
python3 src/make_logos.py             # assets/logos/*_src.* → мөлдір PNG қабаттары
python3 src/render.py                 # → out/final.mp4  (~3 мин, 4 ядро)
python3 src/render.py --stills 2.5,12 # жеке кадрларды тексеру
```
Higgsfield Genjutsu логотипі: `assets/logos/higgsfield_src.png` болса, сол қолданылады. Болмаса, уақытша салынған көшірмесі қолданылады.
